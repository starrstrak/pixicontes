# Décisions structurantes

Chaque décision est volontairement simple et économique ; tout ce qui touche au coût est réglable dans l'admin.

1. **Node.js + TypeScript (Fastify) et SQLite natif (`node:sqlite`).** Une seule techno front/back, aucun module natif à compiler (pas de `better-sqlite3`, donc pas de souci sous Windows), un seul processus à lancer. Requiert Node ≥ 22.5. Les appels OpenAI se font par `fetch` direct (pas de SDK) : moins de dépendances, retries et suivi des coûts maîtrisés.
2. **React + Vite + PWA (`vite-plugin-pwa`).** Installable sur Android, plein écran, histoires déjà créées relisibles hors-ligne (cache réseau-d'abord des API de lecture + images en cache-d'abord). Polices embarquées (Nunito, Atkinson Hyperlegible, OpenDyslexic) : aucun appel externe, aucune télémétrie.
3. **Données 100 % locales** dans `data/` (SQLite, images, cache audio). Seul le texte nécessaire part chez OpenAI ; les e-mails, liens et numéros saisis sont retirés, aucun nom de famille n'est demandé.
4. **Clé API côté serveur uniquement**, chiffrée AES-256-GCM dans la base avec une clé maître locale (`data/.master.key`, droits 600, hors git) ; alternative `.env`. Jamais renvoyée au navigateur (seuls les 4 derniers caractères s'affichent), jamais écrite dans les journaux, exclue des sauvegardes. Un test de bout en bout vérifie qu'elle ne fuit pas.
5. **PIN parent hashé (scrypt)**, verrouillage progressif (5 essais → 1, 5, 15, 60 min), jeton de session en mémoire (30 min glissantes), accès par appui long de 1,2 s sur le logo. Le PIN est créé à la première ouverture de l'espace parent : faites-le à l'installation.
6. **Un seul appel IA par chapitre, en JSON strict (`json_schema`)** : titre, texte, résumé d'une phrase, mise à jour de la mémoire, 3 propositions, prompt d'image. Pas d'erreur de parsing, pas d'appel de résumé séparé.
7. **« Livre de l'histoire » = mémoire structurée** (personnages, lieux, objets, événements, notes de changement) fusionnée localement et renvoyée en version compacte. Les fiches visuelles (anglais) sont créées une fois par l'IA puis **figées**.
8. **Modifier le passé** : un détail changé réécrit le chapitre concerné et ajoute une note de continuité que les chapitres suivants respectent, plutôt que de tout réécrire (coût). L'IA ajuste avec élégance (consigne explicite) au lieu de refuser. Annuler/refaire par instantanés complets (30 niveaux).
9. **Sécurité en trois couches** : filtre local gratuit (FR/EN/DE, bornes Unicode), modération OpenAI avec seuils adaptés à 8 ans (violence légère tolérée pour les dragons, sexuel/haine/automutilation quasi à tolérance zéro), prompt système strict. Un texte refusé n'est **jamais** transmis à l'IA : elle reçoit un ordre de détournement doux. Sortie IA modérée, une régénération, puis message doux. Journal consultable par le parent.
10. **Voix** : `gpt-4o-mini-tts` (instructions de style : calme, enjoué, mystérieux, aventureux ; 6 profils). Lecture **phrase par phrase** avec préchargement des 2 suivantes ; surlignage de la phrase et du mot (estimé proportionnellement à la durée). **Vitesse appliquée côté lecteur** (0,7×–1,3×) : le cache ne dépend pas de la vitesse. Voix « dialogues » optionnelle (phrases commençant par « ou —). `speechSynthesis` désactivé par défaut.
11. **Images** : `gpt-image-1-mini`, qualité *low*, JPEG, une par chapitre ; le prompt = scène + fiches visuelles des personnages cités + style figé + « pas de texte ». Le texte s'affiche d'abord, l'image arrive après (placeholder animé).
12. **Micro** : MediaRecorder → transcription OpenAI avec la langue de l'histoire ; détection de silence locale (rien n'est envoyé si vide), arrêt automatique après 3,5 s de calme, texte corrigeable avant envoi, repli sur la reconnaissance du navigateur si activé. Le micro exige **HTTPS** sur la tablette (voir docs/HTTPS-TABLETTE.md).
13. **Coûts** : chaque appel est comptabilisé (tokens, images, secondes) ; plafond mensuel bloquant ; tarifs éditables car non vérifiés en ligne (voir COUTS.md).
14. **Tests sans réseau ni clé** : un faux serveur OpenAI (`OPENAI_BASE_URL`) alimente les tests de bout en bout.
15. **Mascotte** : le brief contenait un champ non rempli `{{dragon}}` ; j'ai pris « Pixi », un petit dragon vert (SVG animé : calme, joie, réflexion, sommeil). Facile à remplacer dans `frontend/src/components/Mascot.tsx`.
16. **Choix non faits (volontairement)** : pas de comptes, pas de cloud, pas de WebSocket/streaming de texte (chapitres courts : ~3 s suffisent, un écran de chargement animé comble l'attente), pas de voix par personnage individuelle (coût), pas d'achat/pub/lien externe.
